# Gourmet Express - Luxury Food Delivery

Премиальная платформа доставки изысканных блюд от лучших шеф-поваров.

## 🎯 Особенности проекта

- **28 премиальных блюд** (4 в каждой из 7 категорий)
- **Темная роскошная тема** с золотыми акцентами
- **Полноценный каталог** с фильтрами и поиском
- **Корзина** с учетом orderStep (1, 5, 8, 10)
- **Избранное** с localStorage persistence
- **История заказов** с функцией повторного заказа
- **Админ-панель** для управления блюдами и заказами
- **Адаптивный дизайн** для всех устройств

## 📝 Особенности реализации

### Order Step Logic
- `orderStep: 1` - Обычное количество (1, 2, 3...)
- `orderStep: 5` - Кратно 5 (5, 10, 15...)
- `orderStep: 8` - Кратно 8 (8, 16, 24...)
- `orderStep: 10` - Минимум 10 (10, 20, 30...)

### Состояние анимации карточки
- Только одна карточка может быть анимирована одновременно
- Управление через `uiStore.activeAnimatedCardId`

### LocalStorage
- Корзина сохраняется между сессиями
- Избранное сохраняется между сессиями
